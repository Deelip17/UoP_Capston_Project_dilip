# Sample applications

Local demonstration web application used as the system under test, with locators that can be mutated reproducibly (FR-38). Public or synthetic content only.

The application is the package `src/aitaf/sampleapp/` (run `python -m aitaf.sampleapp serve`; see its README). Its baseline DOM snapshots are in `data/dom/shop/` and its 20 requirements in `data/requirements/shop_requirements.md`.
